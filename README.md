# NumPy Game Score Analysis

An introductory data analysis project exploring fictional scores
for three players across five rounds.

## Tools
- Python
- Jupyter Notebook
- NumPy
- Matplotlib

## Analysis
- Calculated each player's mean and standard deviation.
- Compared average scores using a bar chart.
- Visualized scores across rounds using a line chart.

## Findings
- Pixel had the highest average score, at 77, and the lowest
  standard deviation, approximately 1.41.
- Nova's scores increased by 10 points each round, from 55 to 95.
- Echo's average of 70 concealed scores ranging from 40 to 95.

## Limitations
These five fictional rounds describe the observed scores.
They do not establish future player performance.
